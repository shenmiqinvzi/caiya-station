## 安装内容

| 文件 | 用途 |
| --- | --- |
| `CaiYaStation.dll` | 模组程序集 |
| `CaiYaStation.pdb` | 调试符号（便于读日志堆栈） |
| `info.ini` | 模组名、显示名、版本、说明 |
| `preview.png` | 模组菜单预览图 |
| `config.json` | 上限、费率、损耗、护送、保护、寻位、UI、按键 |
| `station-layout.json` | 两张地图的候选锚点与每局站点数 |
| `README.txt` | 游戏内/安装目录说明 |
| `0Harmony.dll` | Harmony 2.4.1，面板打开时拦截原生输入 |
| `LICENSE-Harmony.txt` | Harmony MIT 许可证 |
| `THIRD-PARTY.md` | Harmony 来源与第三方说明 |

## 回滚

若需要回滚，退出游戏后删除/改名 `Duckov_Data\Mods\CaiYaStation`，再把备份目录里的文件复制回去；本模组只写自己的三个存档键，不修改旧模组数据。要彻底清除本模组存档键，需要另做清理脚本（当前未提供，避免误删）。
