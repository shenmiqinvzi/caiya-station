# 菜鸭驿站（CaiYaStation）

《逃离鸭科夫》单机模组。在仓库区与农场镇找到随机出现的“菜鸭驿站”，把背包里带不走或不敢带的物品寄回地堡马蜂自提点；驿站收费、可能丢件，可以花钱和随身物品请护送队降低丢件率。每个驿站每局只能发货一次。

- 目标游戏：本机 Windows Steam《逃离鸭科夫》2.3.30，build 24013657，Unity 2022.3.62f2；单人。
- 当前版本：**0.1.0 垂直切片（代码与离线验证完成，游戏内验收待跑）**。
- 规则基线：[设计文档](docs/菜鸭驿站-设计文档-v0.1.md)。
- 施工与验收：[0.1.0 施工与验收](docs/施工与验收-0.1.0.md)。
- 界面预览（静态设计图）：[0.1.0 界面预览](docs/界面预览-0.1.0.md)。
- 原生接口核对：[0.1.0 原生接口核对](docs/原生接口核对-0.1.0.md)。

## 快速开始

```powershell
.\scripts\Test.ps1      # 81 项纯逻辑与配置测试
.\scripts\Probe.ps1     # 用真实游戏程序集跑原生契约与配置探针（60 项）
.\scripts\Build.ps1     # 编译并生成 artifacts\CaiYaStation-0.1.0.zip
.\scripts\Install.ps1   # 备份旧文件并安装到本机游戏
```

若 PowerShell 因执行策略拒绝运行脚本，用：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\Test.ps1
```

安装后**完全退出并重启游戏**，在模组菜单启用“菜鸭驿站”。进入仓库区或农场镇，打开地图找绿色驿站标记；靠近后按原生交互键打开寄送面板。F8 显示诊断，Esc 关闭面板。

## 已实现（0.1.0）

- 仓库区每局 1 个、农场镇每局 2 个驿站；从候选锚点随机选点并保存，同一 raid 重进不重 roll，新 raid 重新随机。
- 寻位校验：NavMesh、坡度 ≤35°、空间占用、与撤离点 40–80 米（不可满足时逐级放宽并写日志）、与传送点/其它驿站 ≥15 米。
- 驿站模型（柜台/招牌/鸭头/吊灯/旗帜与轻动画）、绿色地图标记、80 米内胶囊标签、画面外边缘箭头、停业变灰落帘；进入区域公告一次。
- 寄送面板：深绿主题、物品图标/品质色条/悬停详情、12 格 / 25 kg 上限、货值、运费、基础/护送后损耗、护送卡片、风险比例条、预计总成本、不可确认原因。
- 回执：结构化“已送达/全部丢失”徽标、送达与丢失清单、运费/护送信息、风味文本。
- 计价 10%（最低 200、最高 5000）；损耗 5%/8%/12%/15%，护送 ×0.6/×0.3、下限 2%、20% 封顶；按堆叠随机并受件数/价值上限约束；单件全损警告。
- 保护规则：任务、钥匙、特殊钥匙、现金、容器、角色物品、不可丢弃物品；名称前缀与 TypeID 黑名单；UI 与结算双重校验。
- 输入保护：面板打开时用独立 Harmony ID 拦截攻击、使用物品、拾取、丢弃、冲刺/瞄准与交互入口，关闭立即解除；目标方法由离线探针核对。拦截不可用且 `Safety.RequireInputGuard=true` 时，驿站面板拒绝打开。
- 二次确认：货值 ≥10000 或单件寄送时，先显示确认页，再次确认才扣费；阈值可在 `config.json` 的 `Safety` 段调整。
- 发货事务：写前日志 → 支付 → 逐件丢失/推送 → 标记已用 → 回执；已推送物品不重复推送，丢失物品写回执。
- 原生存档三个键：`CaiYaStation.State.v1`、`CaiYaStation.World.v1`、`CaiYaStation.Receipts.v1`；不读取旧共享单车键。
- 启动恢复：已付款但中断的发货会继续推送仍在背包的幸存物品；不会二次扣费。
- 回执面板、顶部提示与诊断面板（原生契约、地图、token、背包、缓冲区状态）。

## 设计取舍

- 界面使用运行时生成的 9-slice 圆角纹理与统一主题，不依赖外部资源；物品图标直接取 `Item.Icon`，缺失时用名称首字兜底。
- 驿站先用程序化几何体（亭子 + 柜台 + 鸭头招牌 + 旗帜/吊灯），不依赖自制美术资源；后续可替换。
- 面板用居中 IMGUI，避免压住原生右侧栏；原生交互键打开，Esc 关闭。
- 本版不做基地说明终端、回执历史界面、容器内部物品寄送、联机、驿站升级/声望。
- 不修改护送队价格与物品：拾荒者 1000 + 4 羽毛；雇佣兵 2000 + 4 狗牌。
- 旧 `DuckovSharedBike` 模组不继承、不读写；安装脚本也不删除它。
