菜鸭驿站 0.1.0
==============

这是什么
--------
在仓库区、农场镇的 raid 里会随机出现“菜鸭驿站”（地图绿色标记 + 80 米内屏幕标签）。
靠近后按原生交互键打开寄送面板，把背包里选中的物品寄回地堡马蜂自提点。

规则
----
- 单次最多 12 个堆叠 / 25 kg，只收背包内的物品。
- 运费 = 货值 10%，最低 200，最高 5000；金钱与现金合计支付。
- 损耗按货值分档：5% / 8% / 12% / 15%；按堆叠独立随机，最多丢 30% 件数、
  50% 价值；只寄 1 件时可能全损（面板会提示）。
- 护送（可选，每单最多一队，价格与物品固定）：
  拾荒者团：1000 金钱/现金 + 4 个「虚化的羽毛」，损耗 ×0.6，下限 2%。
  雇佣兵团：2000 金钱/现金 + 4 个「狗牌」，损耗 ×0.3，下限 2%。
  护送物品必须在背包里。
- 每个驿站每局只能成功发货一次；同一局离开再回来不会重 roll。
- 发货后立刻进入马蜂自提点到货缓冲区，回地堡领取；死亡不会丢失已送达物品。
- 零号区没有驿站。

操作
----
靠近驿站按游戏交互键 → 勾选物品 → 选择护送 → “确认发货”。
面板支持整行点击、悬停查看物品详情、Enter 确认、Esc 关闭。
面板打开时会临时拦截攻击、使用物品、拾取、丢弃、冲刺/瞄准和交互输入，避免点按钮时误开枪；
关闭面板后立即恢复。移动不被锁定，走远到 6 米会自动关闭面板。
F8 显示/隐藏诊断面板；80 米内显示距离标签，画面外会在屏幕边缘显示方向箭头。
发货后招牌/旗帜变灰、吊灯熄灭、柜台落帘，请回地堡马蜂自提点领取。

配置
----
config.json：上限、费率、损耗、护送价格/物品、保护标签、寻位、UI、按键、Safety。
Safety 段：
  RequireInputGuard：输入拦截不可用时是否禁止开面板（默认 true，安全优先）。
  ConfirmAboveValue：货值达到多少需要二次确认（默认 10000，0=关闭金额确认）。
  ConfirmWhenSingleStack：单件寄送是否需要二次确认（默认 true）。
Ui.UnlockCursor：打开面板时显示并解锁光标，关闭时恢复（默认 true）。
改配置后重启游戏生效；已有存档中的站点位置不会因此移动。

日志与排查
----------
日志：模组目录 / logs / caiyastation.log
F8 面板显示原生契约状态、地图、存档 token、背包堆叠数、缓冲区状态。
若显示“原生契约失败”，说明游戏版本与模组验证版本不一致，功能会停用而不是带病运行。

兼容
----
新模组、新程序集、新存档键（CaiYaStation.State.v1 / World.v1 / Receipts.v1），
不读取也不修改旧共享单车的 DuckovSharedBike.* 存档。
随包附带 Harmony 2.4.1（MIT，见 LICENSE-Harmony.txt / THIRD-PARTY.md），
只在面板打开时 patch 原生输入入口；关闭面板或停用模组时解除。
与修改背包/仓库/经济/物品的模组可能冲突；首次使用建议备份存档。

本版为 0.1.0 垂直切片，代码与离线测试已完成，游戏内完整验收尚待进行。
代码使用 AI 辅助开发。
